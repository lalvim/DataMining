# Dados da disciplina

## Organização

- `brutos/`: dados originais, preservados sem alterações.
- `processados/`: resultados de transformações reproduzíveis feitas pelos notebooks.

Cada conjunto adicionado deve registrar nome, origem, versão, licença, data de acesso, descrição dos atributos e notebooks que o utilizam. Dados pessoais ou com licença incompatível não devem ser incluídos.

Os primeiros notebooks usam conjuntos pequenos distribuídos pelo scikit-learn ou dados sintéticos gerados com semente fixa, evitando downloads durante a aula.
